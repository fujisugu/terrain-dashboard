# 方格地形互動看板

以 49 個測點高程計算 36 個方格的平均高程、坡度及下坡方向，提供平面坡向圖與可旋轉的 3D 地形圖。

## 使用

開啟 `index.html`，或使用此儲存庫的 GitHub Pages 網址。修改左側高程表即可更新圖形。

- 高程輸入單位：cm；方格邊長預設 20 m。
- A→G 為東，1→7 為南。
- 坡向從真北 0° 順時針計算，東 90°、南 180°、西 270°，指向下坡。
- 3D 可拖曳旋轉、滾輪縮放；高度放大不影響實際計算。
- 支援 Excel 匯入、含公式的 Excel 匯出，以及 PNG 圖像下載。

## 資料與隱私

此版本包含原始 49 點測量值。程式不使用 API Key，無外部程式依賴。匯入資料與計算在瀏覽器內處理；修改儲存在該瀏覽器，不會同步到 GitHub 或其他使用者。請匯出 Excel 備份重要資料。

## GitHub Pages

在 Settings → Pages 選擇 Deploy from a branch，分支選 main，資料夾選 /(root)。網站首頁為 index.html。
